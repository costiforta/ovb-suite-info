Politica de confidențialitate · OVB Suite

Ultima actualizare: 1 octombrie 2026

Ce este aplicația

OVB Suite este o aplicație desktop care rulează exclusiv pe calculatorul consultantului (Adelin). Nu are servere, nu are conturi de utilizator și nu este disponibilă publicului.

Ce date din Google folosește

Cu acordul explicit al utilizatorului, aplicația cere două permisiuni:

  • calendar.events: ca să creeze și să actualizeze în calendarul utilizatorului întâlnirile programate din aplicație și să trimită invitația participantului;
  • adresa de email: ca să arate cu ce cont Google este conectată.

Aplicația nu citește, nu copiază și nu analizează celelalte evenimente din calendar și nu accesează alte date din contul Google.

Unde se păstrează datele

Cheia de acces primită de la Google se păstrează doar pe calculatorul utilizatorului, într-un fișier pe care îl poate citi numai contul lui de utilizator. Nicio dată nu este trimisă către terți, vândută sau folosită pentru publicitate ori pentru antrenarea modelelor de inteligență artificială.

Folosirea informațiilor primite prin API-urile Google respectă Google API Services User Data Policy, inclusiv cerințele de utilizare limitată (Limited Use).

Cum retragi accesul

Accesul se poate retrage oricând din aplicație (butonul „Deconectează”) sau din contul Google, la myaccount.google.com/permissions. După retragere, cheia salvată nu mai funcționează.

In English. OVB Suite is a desktop application running only on the consultant's own computer. With the user's explicit consent it requests the calendar.events scope, used solely to create and update the meetings scheduled from the app and to send invitations, and the user's email address, used to show which account is connected. It does not read or analyze other calendar data. The access token is stored only on the user's computer, readable only by the user's account. No data is shared with third parties, sold, or used for advertising or AI model training. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
